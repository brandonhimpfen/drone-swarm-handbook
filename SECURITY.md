# Security and Safety Reporting

If you find content in this repository that could enable unsafe, abusive, or harmful use of drone systems, please report it by opening an issue marked `safety-review` or contacting the maintainers privately if available.

Examples of content that should be reviewed:

- Operational instructions that could create public safety risks
- Evasion guidance
- Weaponization guidance
- Surveillance misuse patterns
- Dangerous real-world deployment details

This repository is documentation-first and simulation-first. Safety concerns are treated as maintainership issues, not only technical issues.
