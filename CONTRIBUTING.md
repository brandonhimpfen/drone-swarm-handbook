# Contributing

Thank you for helping improve Drone Swarm Handbook.

This project welcomes contributions that improve clarity, safety, technical accuracy, structure, and educational value.

## Accepted contribution types

- New documentation pages
- Safer or clearer explanations
- Diagrams and architecture notes
- Simulation-focused examples
- Glossary improvements
- References to reputable research or standards
- Schema improvements
- Typo and formatting fixes

## Content boundaries

Please do not contribute material that enables harmful or unsafe activity, including:

- Weaponization or targeting workflows
- Evasion of aviation rules, geofencing, remote identification, or safety systems
- Surveillance abuse
- Instructions for unsafe real-world deployment
- Payload guidance for harm
- Covert operation guidance

Simulation-first, educational, and safety-oriented content is welcome.

## Style guide

- Prefer plain language before technical depth.
- Define acronyms on first use.
- Make assumptions explicit.
- Separate conceptual explanation from implementation examples.
- Include safety considerations where relevant.
- Avoid overstating capabilities.
- Use diagrams where they improve understanding.

## Pull request checklist

- [ ] The contribution is educational, research-oriented, or simulation-focused.
- [ ] The contribution avoids unsafe operational instructions.
- [ ] Technical terms are defined or linked.
- [ ] Examples are generic and non-harmful.
- [ ] References are credible and relevant.
