# Simulation Metrics

Metrics help evaluate swarm behavior in a repeatable way.

## Coordination metrics

- Formation error
- Task completion rate
- Reassignment count
- Consensus time
- Agent idle time

## Safety metrics

- Minimum separation distance
- Boundary warnings
- Constraint violations
- Stop condition triggers
- Human review events

## Communication metrics

- Message delay
- Dropped message rate
- Duplicate messages
- Event ordering issues
- Communication availability

## Reliability metrics

- Agent availability
- Mission completion under simulated failure
- Recovery time
- Error rate
- Scenario reproducibility

## Documentation metrics

- Scenario has clear assumptions
- Logs are available
- Results are reproducible
- Known limitations are recorded
- Safety review is complete
