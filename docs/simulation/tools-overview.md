# Simulation Tools Overview

This page lists common categories of tools used in drone and robotics simulation.

## Physics simulators

Physics simulators model motion, forces, sensors, and environment interactions. They are useful for testing assumptions about movement and dynamics.

## Robotics middleware

Middleware supports messages, nodes, services, and distributed system structure.

## Software-in-the-loop

Software-in-the-loop testing allows software components to run against simulated environments.

## Hardware-in-the-loop

Hardware-in-the-loop testing involves physical components and requires substantially more safety oversight. This handbook does not provide field deployment guidance.

## Visualization tools

Visualization helps reviewers understand trajectories, state transitions, formation errors, and safety events.

## Choosing a tool

Evaluate tools based on:

- Documentation quality
- Community support
- Reproducibility
- Logging support
- Scenario configuration
- Safety constraints
- Integration complexity
