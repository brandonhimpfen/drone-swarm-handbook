# Documentation Workflow

This repository is documentation-first. Good documentation should be structured, safe, reviewable, and easy to maintain.

## Workflow

1. Propose a page or improvement.
2. Check whether the topic fits the project scope.
3. Draft content using the style guide.
4. Add diagrams or examples if they improve understanding.
5. Review safety and privacy implications.
6. Submit a pull request.
7. Update navigation or README links where needed.

## Page template

```markdown
# Page Title

Brief introduction.

## Context

Why this topic matters.

## Main concepts

Explain the topic clearly.

## Example or pattern

Use simulation-first, non-harmful examples.

## Safety considerations

Document limitations and risks.

## Further reading

List reputable references.
```
