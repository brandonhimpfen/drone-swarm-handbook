# Agriculture

Agriculture is a common non-harmful domain for studying multi-agent aerial systems.

## Example use cases

- Crop health survey simulation
- Irrigation pattern observation
- Field coverage planning
- Soil condition mapping model
- Pest pressure monitoring using synthetic data

## Coordination patterns

- Grid coverage
- Region-based task allocation
- Formation survey
- Reassignment after simulated battery depletion

## Documentation concerns

- Avoid overstating accuracy.
- Distinguish simulation from real-world sensing.
- Document data assumptions.
- Include privacy considerations for farms, workers, and neighboring properties.
