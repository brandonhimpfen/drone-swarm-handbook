# Release Checklist

Use this checklist before publishing a release.

## Documentation

- [ ] README is current.
- [ ] New pages are linked.
- [ ] Acronyms are defined.
- [ ] Examples are simulation-first.
- [ ] Limitations are documented.

## Safety

- [ ] Unsafe operational guidance is excluded.
- [ ] Safety boundaries are clear.
- [ ] Risk register is reviewed.
- [ ] Privacy-sensitive data is excluded.
- [ ] Contribution boundaries are current.

## Technical

- [ ] Schemas validate.
- [ ] Example JSON files validate.
- [ ] Diagrams are readable.
- [ ] Changelog is updated.

## Governance

- [ ] Version is tagged.
- [ ] License is included.
- [ ] Citation metadata is current if applicable.
