# Responsible Use

Drone swarm documentation should be written with public safety, privacy, accountability, and lawful use in mind.

## Responsible use commitments

- Prioritize simulation-first learning.
- Avoid harmful operational guidance.
- Document assumptions and limitations.
- Make safety constraints visible.
- Use synthetic data in examples.
- Keep human oversight central.
- Review contributions for misuse risk.

## Maintainer review questions

- Could this content be misused?
- Does it provide unsafe operational detail?
- Does it bypass safety, legal, or accountability systems?
- Is the example simulation-only?
- Are privacy-sensitive details removed?
- Are limitations clearly stated?
