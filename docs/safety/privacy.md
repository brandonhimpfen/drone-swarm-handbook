# Privacy Considerations

Drone systems can collect sensitive data, including location traces, imagery, environmental observations, identifiers, and behavioral patterns.

## Privacy principles

- Collect the minimum data necessary.
- Use synthetic or simulated data in examples.
- Avoid personally identifiable data.
- Define retention periods.
- Control access to logs and telemetry.
- Document data flows.

## Documentation checklist

- What data is collected?
- Why is it collected?
- Is the data simulated or real?
- Who can access it?
- How long is it retained?
- Can it identify people, places, or sensitive activity?
- Is aggregation or anonymization possible?

## Example policy statement

This project uses synthetic telemetry examples only. No real personal location data, imagery, or identifying observations should be committed to the repository.
