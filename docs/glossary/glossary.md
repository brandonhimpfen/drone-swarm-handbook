# Glossary

## Agent

An individual drone or simulated drone participating in a system.

## Autonomy

The ability of a system to perform tasks without direct step-by-step human control.

## Collision avoidance

Methods and constraints used to prevent unsafe proximity.

## Consensus

A process by which agents converge on shared information or decisions.

## Formation

A defined spatial arrangement between agents.

## Ground control station

A system used by humans to monitor or manage drone operations.

## Human-in-the-loop

A design where human review, approval, or intervention remains part of the process.

## Mission planner

A component or process that defines objectives, tasks, and constraints.

## Multi-agent system

A system composed of multiple interacting agents.

## Swarm

A coordinated group of agents whose collective behavior supports a shared purpose.

## Telemetry

Recorded or streamed state information about agents, missions, or systems.
