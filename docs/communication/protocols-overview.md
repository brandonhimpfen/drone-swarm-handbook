# Protocols Overview

This page gives high-level context for common robotics and drone communication ecosystems. It is not a deployment guide.

## MAVLink

MAVLink is a lightweight messaging protocol commonly used in drone ecosystems. It is often associated with autopilot systems and ground control software.

## PX4

PX4 is an open-source autopilot ecosystem used in robotics and unmanned vehicle research.

## ArduPilot

ArduPilot is an open-source autopilot suite used for multiple vehicle types.

## ROS 2

ROS 2 is a robotics middleware ecosystem used for distributed robotics applications, simulation, communication, and tooling.

## Documentation approach

When documenting protocol-related behavior, focus on:

- Conceptual role
- Message categories
- Simulation use
- Logging and observability
- Safety constraints
- Human review requirements

Avoid publishing unsafe operational workflows or bypass guidance.
